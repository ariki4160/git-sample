# プロジェクト概要

`git-sample` は、GitHub の基本的な機能を確認するための練習用プロジェクトです。
実アプリ開発ではなく、ブランチ運用・コミット・プルリクエスト・マージといった
一連の Git/GitHub ワークフローの動作確認を目的としています。

## リポジトリ情報

- リポジトリ: https://github.com/ariki4160/git-sample
- オーナー: [ariki4160](https://github.com/ariki4160)
- コラボレータ: [ariki-tomono](https://github.com/ariki-tomono)

## 目的

- ブランチの作成と切り替え
- コミットとプッシュ
- プルリクエスト（PR）の作成・レビュー・マージ
- コラボレータを含む複数アカウントでの共同作業の確認

## ファイル構成

| ファイル     | 内容                                                              |
| ------------ | ----------------------------------------------------------------- |
| `index.html` | メッセージを追記しながらコミット履歴を確認するためのサンプル HTML |
| `test.html`  | プルリクエストの動作確認に使うサンプル HTML                       |
| `code1.py`   | 日付の上旬・中旬・下旬を判定して出力する簡単な Python スクリプト  |

## 実行・確認方法

- `code1.py`: `python3 code1.py` で現在の日付が上旬・中旬・下旬のどれかを判定して出力
- `index.html` / `test.html`: ブラウザで開くだけで表示を確認できる
